# FLY WEB — Web Sistemi ve Uygulama

FLY WEB için hazırlanmış, mobil uyumlu, tek sayfalı tanıtım sitesi.

## Dosyalar
- `index.html` — Sayfa içeriği
- `style.css` — Tasarım ve mobil uyumluluk
- `script.js` — Mobil menü ve dinamik yıl

## Telegram bağlantısı
Sitedeki iletişim butonları `https://t.me/FlyWebSistemi` adresine yönlendirilir.

> Not: Bu bağlantı Telegram kanalınıza gider. Ziyaretçilerin size birebir mesaj göndermesi için kanal açıklamasına veya sabitlenmiş kanal gönderisine kişisel mesaj bağlantınızı (`https://t.me/FlyWebDestek`) ayrıca ekleyebilirsiniz.

## GitHub Pages ile yayınlama
1. GitHub'da yeni bir repository oluşturun (ör. `fly-web`).
2. ZIP içindeki dosyaları çıkarın ve `index.html`, `style.css`, `script.js`, `README.md` dosyalarını repository'nin ana dizinine yükleyin.
3. Repository'de **Settings → Pages** bölümünü açın.
4. **Deploy from a branch** seçin.
5. Branch olarak `main`, klasör olarak `/ (root)` seçip **Save** düğmesine basın.
6. Birkaç dakika sonra GitHub Pages size yayın adresinizi verir.

## Özelleştirme
Telegram adresini değiştirmek isterseniz `index.html` dosyasında `https://t.me/FlyWebSistemi` metnini yeni bağlantınızla değiştirin.

Bu proje statik HTML/CSS/JavaScript kullanır; sunucu veya veritabanı gerektirmez.
